Git & GitHub

Master Git

Git არის ვერსიების კონტროლის სისტემა, ხოლო GitHub გვეხმარება პროექტების ონლაინ შენახვასა და გაზიარებაში.

დავალება 1

Git-ის ძირითადი ცნებები და ბრძანებები

1

რა განსხვავებაა Local Repository-სა და Remote Repository-ს შორის?

Local Repository არის Git Repository, რომელიც მდებარეობს ჩვენს საკუთარ კომპიუტერში. მასში ინახება პროექტის ფაილები, Commit-ები და ცვლილებების ისტორია.

Remote Repository არის Repository, რომელიც განთავსებულია დისტანციურ სერვერზე, მაგალითად GitHub-ზე. მისი დახმარებით შეგვიძლია პროექტის გაზიარება და სხვადასხვა კომპიუტერიდან მუშაობა.

2

რას აკეთებს git push ბრძანება?

git push ბრძანება აგზავნის ჩვენს Local Repository-ში არსებულ Commit-ებს Remote Repository-ში.

მაგალითად, GitHub-ზე ცვლილებების ასატვირთად შეგვიძლია გამოვიყენოთ: 

git push origin main
3

რას ნიშნავს origin Git-ში?

origin არის Remote Repository-ის სტანდარტული სახელი.

როდესაც Local Repository-ს GitHub Repository-ს ვუკავშირებთ, Remote-ს ხშირად ვარქმევთ origin-ს. 

git push origin main

აქ origin არის Remote Repository, ხოლო main არის Branch.

Local vs Remote Repository

Local Repository

მდებარეობს თქვენს კომპიუტერში და მასში ინახება პროექტის ადგილობრივი ისტორია, Commit-ები და ფაილები.

Remote Repository

მდებარეობს ინტერნეტში, მაგალითად GitHub-ზე, და გამოიყენება პროექტის შესანახად, გასაზიარებლად და თანამშრომლობისთვის.

დავალება 2 — GitHub-თან დაკავშირება

Local Repository-ის GitHub-თან დაკავშირების ნაბიჯები

1

შექმენით ახალი Repository GitHub-ზე

GitHub-ზე შექმენით ახალი ცარიელი Repository. შეგიძლიათ არ დაამატოთ README, .gitignore ან License.

2

დააკავშირეთ Local Repository

git remote add origin https://github.com/USERNAME/REPOSITORY.git
3

შეამოწმეთ კავშირი

git remote -v
4

ატვირთეთ Commit-ები GitHub-ზე

git push -u origin main
